Publish a plugin

Sign in with GitHub to publish. The store asks GitHub who you are and whether you belong to Falcon-MC; it never writes to your account.

  1. A public repo you administer, with a plugin.json at the root.
  2. Each GitHub release is a version: attach the .wasm, .jar or native libraries.
  3. Pick your repo and up to three categories, then submit.
  4. An administrator checks it before it is listed.
Files, images and review
  • Files: at most 32 MB each. Native plugins ship one library per platform: .so Linux, .dll Windows, .dylib macOS, with x86_64 or arm64 in the name if you ship both. Drafts and pre-releases are skipped.
  • Images (optional): "icon" and "banner" in plugin.json, paths in the repo. PNG, JPEG or WebP. Logo square, 64 to 512 px, 256 KB max. Banner about 3:1, up to 1600×600, 1 MB max.
  • Updates: click Check for new releases. New Wasm versions go out once checked; native and Java versions, and new images, wait for an administrator.
  • A release file replaced after its check hides that version until it is checked again.
