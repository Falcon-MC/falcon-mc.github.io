Plugins

Publish a plugin

Sign in with GitHub to publish. The store asks GitHub who you are and whether you belong to Falcon-MC; it never writes to your account.

  1. The plugin lives in a public GitHub repository you administer, with its plugin.json at the root.
  2. Each version is a GitHub release with one .zip (or a single .wasm, .jar or library) of at most 32 MB. Drafts and pre-releases are skipped.
  3. An administrator reads the plugin before it is listed. After that, new Wasm versions are listed once the store has checked them; native and Java versions wait for an administrator.
  4. A release file replaced after it was checked hides its version until it is checked again.
