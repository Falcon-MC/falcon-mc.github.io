Commands

On this page

  • Server
  • Moderation
  • Players
  • World
  • Blocks
  • Entities
  • Display and logic
  • Game rules

Players type a leading slash, the console does not. The Level column is the permission the command requires: see Permissions. Op means operator level (GameDirectors), Any means every player, and Console means a level above operator, which no player has.

Server

CommandLevelUse
/about (/version, /ver)AnyShows the server version and commit
/statusOpShows server performance and players
/profiler <on|off|status>OpRecords a report to profiler/
/listOpLists online players
/say <message>OpBroadcasts a message
/stopConsoleStops the server
/save [hold|resume|query]ConsoleSaves or holds saving
/save-on, /save-offConsoleTurns saving on or off
/setmaxplayers <maxPlayers>ConsoleChanges the player limit
/transfer <player> <address> [port] (/transferserver)ConsoleSends a player to another server
/world <list|create|load|unload|tp> ...ConsoleSee Worlds

Moderation

CommandLevelUse
/op <player>OpGrants operator
/deop <player>OpRemoves operator
/kick <player> [reason]OpDisconnects a player
/ban <player> [reason]OpBans a player
/pardon <player> (/unban)OpRemoves a ban
/ban-ip <address|player> [reason]ConsoleBans an address
/pardon-ip <address> (/unban-ip)ConsoleRemoves an address ban
/banlist [ips|players]OpLists bans
/allowlist <on|off|list|reload> (/whitelist)OpManages the allow list
/allowlist <add|remove> <player>OpEdits the allow list

Players

CommandLevelUse
/gamemode <mode> [player] (/gm)OpChanges a game mode
/defaultgamemode <mode>OpChanges the default mode
/give <player> <item> [amount] [data]OpGives an item
/clear [player] [itemName] [data] [maxCount]OpRemoves items
/enchant <player> <enchantment> [level]OpEnchants the held item
/effect <player> <effect> [seconds] [amplifier] [hideParticles]OpApplies an effect
/xp <amount>[L] [player]OpAdds experience or levels
/spawnpoint [player] [x y z]OpSets a spawn point
/clearspawnpoint [player]OpClears a spawn point
/tag <targets> <add|remove|list> [name]OpManages tags
/me <action>AnySends an action message
/tell <target> <message> (/msg, /w)AnySends a private message

World

CommandLevelUse
/time <add|set|query|start|stop> ...OpReads or changes the time
/weather <clear|rain|thunder> [duration]OpChanges the weather
/daylock [lock] (/alwaysday)OpLocks the day cycle
/difficulty <peaceful|easy|normal|hard>OpChanges difficulty
/gamerule <rule> [value]OpReads or sets a rule, listed below
/seedOpShows the seed
/setworldspawn [x y z]OpSets the world spawn
/locate biome <biomeName> [teleport]OpFinds a biome. Players only
/tickingarea <add|remove|remove_all|list|preload> ...OpManages ticking areas

Blocks

CommandLevelUse
/setblock <x> <y> <z> <block> [replace|destroy|keep]OpPlaces a block
/fill <x1> <y1> <z1> <x2> <y2> <z2> <block> [replace|destroy|keep|hollow|outline]OpFills a volume
/testforblock <position> <tileName>OpTests a block
/testforblocks <begin> <end> <destination> [masked|all]OpCompares two volumes

Entities

CommandLevelUse
/tp [victim] <destination|x y z> (/teleport)OpTeleports
/summon <entityType> [x y z] [nameTag]OpSpawns an entity
/kill [player]OpKills a target
/damage <target> <amount> [cause]OpApplies damage
/testfor <victim>OpTests for a target

Display and logic

CommandLevelUse
/execute <subcommand> ... run <command>OpRuns a command in a context
/title <player> <clear|reset|title|subtitle|actionbar|times> [text|fadeIn stay fadeOut]OpShows a title
/titleraw <player> <clear|reset|title|subtitle|actionbar|times> [json]OpShows a raw JSON title
/tellraw <target> <raw json message>OpSends raw JSON text
/camera <target> <clear|fade|set> ...OpControls a camera
/particle <effect> [position]OpSpawns a particle
/playsound <sound> [player] [position] [volume] [pitch] [minimumVolume]OpPlays a sound
/stopsound <player> [sound]OpStops a sound

Game rules

Rule names are lowercase. Defaults are in parentheses.

  • Cycles: dodaylightcycle (true), doweathercycle (true), doinsomnia (true), randomtickspeed (1)
  • Damage: drowningdamage, falldamage, firedamage, freezedamage, pvp (all true)
  • Drops: doentitydrops, domobloot, dotiledrops (all true), keepinventory (false)
  • Mobs and world: domobspawning, mobgriefing, dofiretick, tntexplodes, tntexplosiondropdecay, projectilescanbreakblocks, respawnblocksexplode (all true)
  • Players: naturalregeneration (true), doimmediaterespawn (false), spawnradius (5), playerssleepingpercentage (100), dolimitedcrafting (false), recipesunlock (false)
  • Display: showcoordinates, showdeathmessages, showtags, showbordereffect, showrecipemessages, locatorbar (all true), showdaysplayed (false), playerwaypoints (1)
  • Commands: commandblocksenabled, commandblockoutput, sendcommandfeedback (all true), functioncommandlimit (10000), maxcommandchainlength (65535)
  • Other: experimentalgameplay (true)
