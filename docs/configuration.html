server.properties holds one key=value per line. There are 76 keys. Each value is validated when the file is read: a bad value is reported in the log and the default is used.

Booleans accept true, false, 1 and 0, except movement-simulation, simulation, server-authoritative-block-breaking and disable-client-vibrant-visuals, which accept only true and false.

Identity and rules

KeyDefaultEffect
server-nameFalcon ServerName shown to clients
languageen_USServer language
gamemodesurvivalsurvival, creative, adventure or spectator. Numbers 1, 2 and 6 also map to the last three
difficultyeasypeaceful, easy, normal or hard
allow-cheatstrueSets the commands-enabled flag sent to clients
max-players101 or more
default-player-permission-levelmembervisitor, member or operator
spawn-protection16Radius around spawn where non-operators cannot change blocks
disable-player-interactionfalseSent to clients in the start-game data

Network

KeyDefaultEffect
server-port19132IPv4 port, 1 to 65535
server-portv619133IPv6 port, 1 to 65535
transportnethernetThe only accepted value
online-modetrueChecks Xbox Live authentication at login
network-encryptiontrueEncrypts the connection
enable-lan-visibilitytrueAnnounces the server on the LAN
allow-listfalseOnly allowlist.json entries can join. An empty list logs a warning
any-versionfalseLets every supported protocol join, not only the newest. Ignored while allow-unofficial-clients is off
allow-unofficial-clientsfalseTurns every client check off, see Client checks and telemetry
allow-lan-without-identityfalseLets LAN players from a private address join without an identity assertion
emit-server-telemetryfalseSends anonymous reports to the Falcon service, see Client checks and telemetry
compression-threshold10 to 65535, sent to clients in the network settings
compression-algorithmzlibzlib or snappy

With any-version on, older clients still receive the blocks, items and recipes of the newest version, and the server logs a warning. The client checks only know how the newest version behaves, so any-version only takes effect with allow-unofficial-clients=true; otherwise the server logs an error at start and keeps the newest version only.

Movement and block breaking

KeyDefaultEffect

player-position-acceptance-threshold0.5Squared distance, in blocks, between the reported and simulated position above which movement is corrected

A file without movement-simulation keeps its simulation value, or turns the simulation on when strict mode is on.

Join by address

The client tries HTTPS before HTTP on the signaling port, and beside port 19132 it also tries 443 and 80.

KeyDefaultEffect
signaling-certificateemptyPEM certificate chain for HTTPS on the signaling port
signaling-private-keyemptyPEM private key of that certificate
signaling-extra-port0Second signaling port, 0 for none. Set 443 so clients typing port 19132 join without waiting
signaling-acme-domainemptyDomain players type. When set, the certificate is obtained and renewed with ACME into certificates/
signaling-acme-emailemptyContact address sent to the ACME directory
signaling-acme-directoryLet's EncryptACME directory URL, https:// only
signaling-acme-challengetls-alpn-01tls-alpn-01 answers on TCP 443, http-01 on TCP 80

A complete certificate and key pair takes precedence over ACME.
