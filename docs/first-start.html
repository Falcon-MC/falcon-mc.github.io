The setup wizard

Run FalconServer in a terminal. When server.properties is needed, the wizard:

  1. Asks for a language.
  2. Shows the LGPL-3.0 notice and asks you to accept it. Refusing stops the server.
  3. Asks whether to configure now. Answering no writes the defaults.
  4. Goes through four steps, then prints a summary.
StepAsks for
Serverserver-name, gamemode, difficulty, max-players
Networkserver-port, server-portv6, online-mode, enable-lan-visibility
Worldlevel-name, level-seed, view-distance
PlayersOperators, allow-list and the allowed players

The wizard only runs when both input and output are a terminal, so it stays out of the way under a service manager or in a container.

Command-line options

OptionEffect
--no-wizardSkips the wizard
--accept-licenseSkips the license question
--language=fr_FRSets the wizard language

The server ships with 29 language files.

Joining

Add the server in the client's server list with the machine's address and server-port (19132 by default). With enable-lan-visibility=true it also appears on the LAN.

Falcon's transport is NetherNet. Without a certificate its signaling endpoint serves plain HTTP: see Join by address. RakNet is no longer accepted: see Troubleshooting.

Using the console

The console takes the same commands as players, without the slash. It holds more permission than any player: see Permissions.

op Steve
allowlist add Alex
stop

Updating

Stop the server and replace the executable. Worlds use the Bedrock format, and an internal plugin must be rebuilt for each server build: see Internal plugins.
