What Falcon is

Falcon is a server you run yourself for Bedrock clients. The protocol, world storage, inventory, movement and gameplay are all implemented in this project, with vanilla behavior as the reference. It ships as one native executable, reads Bedrock worlds unchanged, and is extended through behavior packs, scripts and plugins.

What you can do with it

  • Run several worlds

    Create, load, unload and move players between worlds at runtime with /world. Each world has its own Overworld, Nether and End.

  • Play the real dimensions

    Nether and End generators, portals, and terrain, biomes and features generated from the seed.

  • Load behavior packs

    Packs from folders or .mcpack, .mcaddon and .zip archives.

  • Script in JavaScript

    The Script API modules @minecraft/server and @minecraft/server-ui: events, entities, forms, scoreboards and item custom components.

  • Add custom content

    Custom blocks, items and entities, from JSON in a pack or from a plugin.

  • Write plugins

    Sandboxed WebAssembly, native C++ or Java, on one API with more than 60 event types, commands, a scheduler, permissions and services.

  • Hook packets

    Read, rewrite, cancel or send raw packets from a plugin, per player.

  • Defend villages

    Villages with points of interest and dwellers, and raids with waves, a boss bar and the Hero of the Village reward.

  • Administer it

    More than 50 commands, 64 settings, per-second rate limits and /profiler HTML reports.

  • Match vanilla terrain

    The parity tool measures 99.6% block match against Bedrock Dedicated Server on a test seed and 98.1% on seed 42, over 32×32 chunks. Structures are in progress.

Start in a minute

Download a build from the releases page, or build it:

git clone https://github.com/Falcon-MC/Falcon.git
cd Falcon
./build.sh
./build/Falcon.Server/FalconServer

The first start runs a setup wizard in the console and writes server.properties. Then add the server in your Bedrock client, on port 19132 by default.
